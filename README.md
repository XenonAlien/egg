# Оптимальный алгоритм для задачи о яйцах.

Вы находитесь на первом этаже здания с сотней этажей. У вас 2 яйца. Вам необходимо найти N высоту, при которой яйца будут разбиваться (за максимальное количество попыток).
Высота разбивания (n) не меняется.

## Использование
```python
from egg_drop import egg_drop

def your_egg_test(floor):
    return floor >= 64  # Ваша логика

floor, attempts = egg_drop(100, your_egg_test)
