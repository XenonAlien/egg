# 🥚 Optimal Egg-Dropping Algorithm  
**Автор**: [Xenon]  
**Дата**: 2025    

## 🔥 Суть метода  
Гибридный алгоритм для задачи о яйцах и небоскрёбе:  
1. **Фаза 1**: Экспоненциальный поиск (`1, 2, 4, 8...`).  
2. **Фаза 2**: Бинарный поиск в найденном диапазоне.  

**Максимум попыток для 100 этажей**: **13** (классика — 14).
