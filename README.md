# Оптимальный алгоритм для задачи о яйцах.

Вы находитесь на первом этаже здания с сотней этажей. У вас 2 яйца. Вам необходимо найти N высоту, при которой яйца будут разбиваться (за максимальное количество попыток).
Высота разбивания (n) не меняется.

Моё решение:

Для начала используем метод минимизации энтропии (книга: Теория Игр)
среднее от 100 это 50 (100/2=50).
Если шар разбился, то высота n находится от 1 этажа, до 50. Спускаемся ниже
50/2=25
25/2=12,5
12,5/2=6,25
6,25/2=3,125
3,125/2=1,5
=> 5-6 попыток. Но так же есть промежуточные этажи, например на 25 этаже шар может разбится. Значит от 25 до 50. Теперь считаем просто среднее арифметическое (бинарный способ)
75/2=37,5
87,5/2=43,75 и так далее.
В идеале тогда начать с 1 этажа, чтобы долго не считать и к тому же чтобы избежать разбивание шара на 50 этаже.
1*2=2
2*2=4
4*2=8
8*2=16
16*2=32
32*2=64
дальше проблема, т.к если умножать 64 на 2 то выйдет 128, а всего этажей 100. После 64 ищем среднее арифметическое. Если на 64 этаже шар разбился, то высота n находится в промежутке 32; 64. Если не разбился, то в промежутке 64; 100
Найдем худший вариант через разницу
64-32=32
100-64=36. Будем двигаться к 100
среднее между 64 и 100 это 164/2=82.
182/2=91
191/2=95
195/2=97
197/2=98
99
высота найдена. нет смысла кидать с 100 и тратить попытку.
выходит 6 попыток. Для этажей > 1000 можно использовать тирнарный способ.

    return floor >= 64  # Ваша логика

floor, attempts = egg_drop(100, your_egg_test).
